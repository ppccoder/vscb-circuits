🧭 Filtre « vent »

La direction choisie indique d'où vient le vent. Sont retenus les circuits dont la 1re moitié se fait face au vent (on part vers le vent) et la 2e sous le vent (on revient avec le vent). Le bouton central active / désactive le filtre.

💾 Mes parcours roulés

Parcours GPX importés sur cet appareil (mémorisés par le navigateur). Les parcours publiés dans parcours_roules_vscb.json sur GitHub sont rechargés automatiquement à chaque démarrage. « Sauvegarder » les enregistre dans ce fichier JSON à conserver ou copier sur un autre appareil ; « Charger » les restaure depuis ce fichier (fusion, sans écraser les vôtres).

👥 Effectifs par sortie

Nombre de cyclistes présents à chaque sortie (mémorisé sur cet appareil) ; les sorties à 0 ne sont pas listées. « Sauvegarder » exporte tous les effectifs dans un fichier JSON ; « Charger » restaure depuis un fichier JSON (fusion avec les vôtres).
